# Secret Birthday Gift 🎁

A responsive birthday surprise website built with plain HTML, CSS and JavaScript.

## 1. Customize it
Open `script.js` and edit:
- `passcode`: the code the recipient enters
- `recipientName`: the recipient's name
- `personalMessage`: your personal birthday note

The default passcode is `2011`. Change it before sharing.

## 2. Add your pictures and GIFs
Put your own files in the `assets` folder using these exact names:

- `memory1.jpg` through `memory5.jpg`
- `shinchan-birthday.png`
- `shinchan-dance.gif`

Optional extras you can add for future customization:
- `shinchan-excited.gif`
- `shinchan-gift.gif`
- `shinchan-pleading.gif`
- `shinchan-wrong.png`

If a memory photo or dance GIF is missing, the page displays a friendly placeholder instead. Use images/GIFs you have permission to share.

## 3. Preview it
Open `index.html` in a browser. For best results, test on a phone-sized screen too.

## 4. Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new repository, e.g. `secret-birthday-gift`.
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then save.
7. Wait for the Pages deployment and open the website URL shown there. It usually looks like `https://YOUR-USERNAME.github.io/secret-birthday-gift/`.
8. Send that URL to the birthday person.

## Important privacy note
The passcode in this starter project is only a playful unlock screen. Because the code is inside `script.js`, anyone with technical knowledge can view it. Do not put private photos or confidential information on a public site. For genuinely private content, use a service with real authentication or keep the page unlisted and avoid sensitive material.

## Files
- `index.html` — page structure
- `style.css` — colors, layout and animations
- `script.js` — passcode, confetti and customization
- `assets/` — your images and GIFs
